**1.3初始化**

```c++
#include <iostream>
#include <string>
using namespace std;

//C++11 支持在类内部直接给非静态数据成员设置默认值
class base
{
public:
	int a{ 10 };
	double b{ 33.4 };
	char ch{ 'c'};
	string str{ "lichermionex" };
	string str2{ 10, 'a'};

// 静态的正向可以初始化在内部的,必须是正向
	static const int e1{ 55 };
	const static int e2{ 55 };

// 其它的
	static double e3;
	static char  e4;
	static const char* e5;
};

double base::e3 = 4.3;
char base::e4 = 'a';
const char* base::e5 = "fffffffff";

int main()
{

	return 0;
}
```

**C++11 允许在成员声明时直接指定默认初始值，构造函数只需要初始化与默认值不同的成员。**



**1.4 final**

**final:**

**1.修饰派生类的虚函数，表示该虚函数不能够被重写了**

**2.修饰派生类，表示该派生类不能够被重写了的、**

```c++
#include <iostream>
#include <string>
using namespace std;

class base
{
public:
	virtual void test()
	{
		cout << "base ..." << endl;
	}
};

class child final : public base
{
public:
	virtual void test() final
	{
		cout << "child ... " << endl;
	}
};

class granchind final : public base
{
public:
	virtual void test()  final
	{
		cout << "granchind ... " << endl;
	}
};

int main()
{
	child lic;
	lic.test();

	granchind gran;
	gran.test();

	return 0;
}
```

**1.8 静态断言**

```c++
#include <iostream>
#include <cassert>
using namespace std;

char* createArray(int size)
{
	assert(size > 0);
	char* array = new char[size];

	return array;
}

int main()
{
	char* buf = createArray(10);
}
```

**这是动态断言：运行期间才知道需要判断的条件是否满足的**

```c++
#include <iostream>
#include <cassert>
using namespace std;

int main()
{
	static_assert(sizeof(long) == 4, "这不是64位机器");

}
```
